# Mapowy trening

79 miast Polski i 20 powiatów województwa lubelskiego. Zawiera poprawione, klikalne granice powiatów.

## Uruchomienie na komputerze
Otwórz index.html w przeglądarce. Obrazy mapy, kod i style są wbudowane w ten plik. Czcionki Google są opcjonalne.

## GitHub Pages
1. Utwórz publiczne repozytorium.
2. Wgraj zawartość tego ZIP-a do głównego katalogu repozytorium (bez dodatkowego folderu).
3. Wejdź w Settings → Pages.
4. Wybierz Deploy from a branch, gałąź main i folder / (root), a następnie Save.
5. Po publikacji GitHub pokaże link do gry.

Gra nie wymaga serwera, instalowania pakietów ani logowania. Wyniki zapisuje lokalnie w przeglądarce.
